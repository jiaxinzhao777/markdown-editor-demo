# 采集标准编辑器选型

[Demo 地址](https://jiaxinzhao777.github.io/markdown-editor-demo/) · 2026-10-26

这次主要看采集标准的编辑体验，尤其是业务人员能不能直接修改表格，以及现有 Markdown 文档能否继续使用。

## 建议

先用 MDXEditor 做业务接入验证。Demo 中已经试过表格增行、填写和保存重开，这些操作能完成；标题、列表、图片和代码块也有入口，源码和差异视图可以用来核对修改。需要先处理两个问题：复杂样例会报解析错误，部分提示还是英文。拿真实历史标准验证通过后，再决定是否替换现有编辑框。

Milkdown 留作备选。它的正文界面更简洁，有斜杠菜单和块操作，适合连续写文档。不过部分功能要选中或悬停才出现，需要确认业务人员能否找到这些入口。

TOAST UI 的中文表格菜单比较清楚，但官方仓库已在 2026-09-02 归档。新项目采用它，后续修复和适配就要自己承担，因此不放在首选。[仓库状态](https://github.com/nhn/tui.editor)

## 各方案的取舍

| 编辑器 | 优点 | 问题 | 建议 |
| --- | --- | --- | --- |
| MDXEditor | 直接编辑正文和表格，有源码、差异视图；已验证表格增行和保存重开。 | 复杂样例解析失败；英文提示较多，窄弹窗里工具栏拥挤。 | 先验证真实历史文档，兼容性通过后优先考虑。 |
| Milkdown / Crepe | 界面简洁，有表格、任务列表、斜杠菜单和块操作。 | 操作入口比较隐蔽，中文提示和弹窗排版还要调整。 | 备选，重点看长文档和表格编辑是否顺手。 |
| TOAST UI Editor | 中文工具栏，表格菜单有增删行列和对齐，已试过增行。 | 官方仓库已归档，后续维护成本需要自己承担。 | 作为表格交互参考；有维护人力再考虑采用。 |
| Vditor | 中文提示，能切换源码、即时渲染和所见即所得模式。 | 模式较多，需要统一使用方式；当前工具栏没有插图入口。 | 团队确实需要多种编辑模式时再选。 |
| BlockNote | 块操作直观，表格、任务列表等内容能直接展示。 | Markdown 导入导出有损；完整保存块属性更适合用 JSON。 | 当前不优先，需要建设块式文档产品时再考虑。 |
| uiw / React MD Editor | 工具栏和双栏预览齐全，与现有页面接近，改动较小。 | 表格仍要改 Markdown 源码，预览侧不能直接编辑。 | 可以保留源码编辑方式，但解决不了业务人员改表格的问题。 |
| md-editor-rt | 中文工具栏、目录和预览较完整，有表格插入入口。 | 仍以源码编辑为主；Demo 中公式、绘图等扩展没有开启。 | 用户熟悉 Markdown、又需要目录时可考虑。 |
| Tiptap + Markdown | 可定制工具栏和业务组件，已接入表格、图片、任务列表扩展。 | 当前只有基础表格插入按钮，行列管理和图片插入 UI 还要做。 | 有明确的自定义组件需求再投入，当前接入工作偏多。 |
| CodeMirror 6 | 直接编辑原文，有高亮、查找和撤销。 | 编辑区只有源码，工具栏、预览和表格操作需要另做。 | 留给技术人员维护复杂 Markdown。 |
| EasyMDE | 基础工具栏和预览够用，可以插入表格语法。 | 表格仍靠源码修改，当前没有比 uiw 更明显的收益。 | 本次不优先。 |

这里比较的是文档里的静态表格。合并单元格、复杂表头，以及带分页、筛选的数据表格，需要单独评估。Demo 里的图片上传和业务发布也还没有接后端。

## 商用

按当前安装版本核对，以上方案的开源核心都允许商用，主要区别如下：

| 范围 | 商用要求 |
| --- | --- |
| 除 BlockNote 外的 9 个方案，当前使用的开源包均为 MIT | 可以免费用于收费产品和闭源系统，发布时保留版权和许可声明，不要求公开业务源码。[MIT 条款](https://raw.githubusercontent.com/nhn/tui.editor/master/LICENSE) |
| BlockNote 的 core、react、mantine 包为 MPL-2.0 | 可以商用。对外分发时，要提供 MPL 覆盖代码的源码获取方式；修改这些文件后，也要按 MPL 提供对应修改。独立业务代码可以闭源。发送到浏览器的 JavaScript 同样属于分发。[Mozilla 说明](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) |
| BlockNote XL、Tiptap 付费扩展和云服务 | 另看对应授权。BlockNote XL 为 GPL-3.0 或商业授权，闭源集成通常需要购买商业授权；当前 Demo 没用 XL 包。Tiptap 的免费核心也不包含所有付费功能。[BlockNote 许可](https://github.com/TypeCellOS/BlockNote/blob/main/LICENSE.txt)、[Tiptap 说明](https://tiptap.dev/product/editor) |

从授权成本看，MDXEditor 和 Milkdown 都没有额外的核心包商用费用。上线前仍需整理实际使用的第三方许可；本次没有逐个核查全部间接依赖。
